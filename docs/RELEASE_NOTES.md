# 0.1.0 MVP

Worker 中文管理页适配电脑横屏和手机竖屏，展示 5 小时 / 每周剩余额度及重置倒计时。本次线上更新仅替换页面，保留原登录与额度后端。

Android 新增下拉快捷设置额度块；小米控制中心隐藏文字时，图标本身显示上下两行百分比（5 小时 / 每周）。点击刷新，长按打开应用，旧数据标记“上次”。

本地验证：Worker 20 项、Flutter 10 项、Android JVM 5 项、Python 8 项测试通过；Flutter 静态检查、Worker 类型检查、Release APK 构建通过；新小米手机覆盖安装成功，数字图标已从真机截图确认。

APK 使用当前开发密钥签名，供自用测试，可覆盖之前的安装。不是应用商店正式签名。后台刷新受系统省电限制；实验性 OpenAI 接口可能变化。

当前线上服务通过管理页只读令牌连接 App。源码中此前的连接码与后端诊断扩展未在本次线上更新中部署，详见 docs/STATUS.md。

发布目标：私有仓库 tonygyf/codex-meter-cn；保留现有仓库可见性。附件包含 APK、源码包和 SHA-256 校验值，不含私有配置或凭证。
