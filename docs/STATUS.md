## 发布与限制

Release APK 使用当前开发密钥签名，以便覆盖已有安装、保留本地配置；供自用测试，尚不是应用商店正式签名。GitHub Actions 定义已提供；发布目标为私有仓库 tonygyf/codex-meter-cn，远程构建与 Release 结果以 GitHub 为准。

源码中还包含此前未上线的连接码及后端诊断草稿；本次按用户要求没有部署这些后端草稿，不能假设当前服务支持一次性连接码。继续用管理页显示的只读令牌连接 App。后续部署前应审查本地后端差异。

实验性 OpenAI 额度接口可能变化，国内网络连通性不作保证。Android 后台刷新周期与提醒受系统省电限制。此轮未重测重启、长时间省电、通知投递的全部场景。
