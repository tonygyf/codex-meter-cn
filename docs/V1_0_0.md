# 1.0.0：自动监测与水位组件

升级保留原有数据源、令牌与缓存。默认常驻通知，每 3 分钟读取网关；设置中可选择 1 / 3 / 5 / 10 分钟或关闭常驻，改用省电后台刷新。通知、快捷块和组件共享原生缓存。App 可见时每 15 秒读取缓存，不额外轮询网络。

## 组件

整个组件是液体容器，水量对应 **5 小时剩余百分比**，不是卡片内的瓶子插画。

| 尺寸 | 内容 |
| --- | --- |
| 2×1 | 仅 5 小时百分比、细进度条和整面水位 |
| 2×2 | 5 小时主数字、每周额度摘要 |
| 2×3 或更高 | 双额度、重置时间、采集时间 |

分层依据启动器提供的 dp 宽高，格数因桌面网格而异。支持横向、纵向拖动缩放；最小值允许约 2×1，实际格数由启动器决定。

组件右上角「…」可独立更改水位 / 电量条、薄荷 / 深海 / 暖沙、动态水面开关。App 首页提供尺寸预览和新组件的默认外观设置。

水面有两层复合波形，32 帧、100ms 间隔循环，使用不同方向与谐波产生非匀速视觉；不是物理流体模拟。原生 ViewFlipper 在启动器侧播放，刷新额度时才生成新帧；位图内存按设备像素及响应式尺寸数设预算。可关闭动态以节电；启动器、省电或屏幕不可见时可能暂停动画。

未知额度显示横线，不显示满水；过期、离线或重置时间已到时标注「上次」，不推断额度已恢复。

## 图标

默认 A「涟漪环」，按所有者选择。B「水滴环」、C「水量瓶」也内置，App 内可切换。源文件在 `design/icons/`；Android 包含原生矢量、自适应与单色版本。

## 系统限制

Android 15+ 的 dataSync 前台服务总计约 6 小时 / 24 小时。超时后停止常驻，保留 WorkManager 约 15 分钟的省电刷新；返回可见 App 后尝试恢复。没有使用其他服务类型绕过时限。系统强行停止、厂商清理、深度休眠仍会延迟更新，不能承诺全天候准点。通知、电池与自启动策略可通过 App 的系统设置入口调整。

Worker 有独立采集周期；手机更频繁读取不代表上游已经产生新快照。沿用原时间戳，不修改云端登录或采集逻辑。
